# recipe-manager-frontend

The React 19 + Vite SPA for RecipeManager. Setup, commands and troubleshooting live in the
[root README](../../README.md#frontend); versions and tooling choices in
[docs/tech-stack.md](../../docs/tech-stack.md).

```bash
npm install
```

```bash
npm run dev
```

Serves on `http://localhost:3000`. Start the API first — there is no mock backend.
